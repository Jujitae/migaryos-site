6 · 실행 경로

Agent / local / private

다운로드한 동일 request를 승인된 로컬 환경에서 위 CLI로 실행할 수 있습니다. 모니터는 별도 private ledger가 필요하고 주문은 항상 OFF입니다.

이 public 페이지에는 존재하지 않는 /api/world/research 호출이나 계산 Run 버튼을 만들지 않았습니다.

7 · 결과 / 비교

아직 공개 결과 artifact가 없습니다. 로컬 결과 JSON을 Advanced에서 불러오면 이곳에 실제 필드만 표시합니다.

Advanced / Raw request · result · file upload

폼과 이 영역은 모두 wie.quant-request/1 및 wie.quant-result/1 계약을 사용합니다. row hash와 exact timestamps를 보존해야 하는 사용자를 위한 경로입니다.

업로드된 결과는 schema가 wie.quant-result/1일 때만 표시합니다. 원시 파일·hash·metadata의 보관은 실행 환경의 책임입니다.

검증 경계

연구 계산이 COMPUTED가 되어도 validation_status: UNVALIDATED, promotion_allowed: false, orders: OFF입니다. synthetic 입력은 실증 증거가 아닙니다.

후보·백테스트 기록은 현재 public registry에 자동으로 생기지 않습니다. 수익 보장이나 매매 성공률을 주장하지 않습니다. 미래 성과 표현도 하지 않습니다.

Execution Plane · Founder 전용 · 잠김. 브로커 권한, 손실 한도, kill switch, 원장, reconciliation, 불변 감사 로그와 단계별 증거가 없으면 live order를 켜지 않습니다.

기존 선별 게이트와 필수 검증

이 수치는 통과 판정이 아니라 후보 선별용 기준입니다: Sharpe >= 1.5 · Max drawdown < 15% · Hit rate >= 55% · t-stat >= 2.0. 모든 후보에는 비용·슬리피지, OOS·워크포워드, purged/embargoed CV, DSR/PBO, capacity, paper·canary, 독립 재구현이 필요합니다. Kelly는 raw 포지션 크기 명령이 아닙니다.
