내 자료로 연구 실행

출처와 관측 시각을 포함한 wie.quant-request/1 JSON을 입력하세요. 파일 선택은 브라우저에서 읽기만 하며, 연구 실행을 누르면 현재 서버에 전송합니다. 결과는 이 화면에만 표시하고 공개 집계에 더하지 않습니다.

각 서식은 형식을 살펴볼 수 있는 합성 자료 90행입니다. 불러오기만으로 계산하거나 전송하지 않습니다. 실제 기록을 검토하려면 해당 시점에 관측한 수치 자료와 출처를 따로 준비하세요.

필요한 자료와 입력 계약 · 행 수정 후 해시 만들기

위 서식을 선택하면 모든 필드가 포함된 편집 가능한 JSON이 아래에 열립니다. 요청은 schema, family, as_of, dataset, config로 구성됩니다. 시각은 UTC Unix 초이며, as_of 이후의 사건이나 당시 아직 알려지지 않은 값은 계산에서 제외합니다.

  • 두 자산 가격: 같은 시점의 y, x 가격과 y_volume, x_volume 거래량. 자료 종류는 paired-prices입니다.
  • 팩터 분해: 조정 기준이 일치하는 price, asset_return, risk_free_return, 이름이 일관된 factors와 volume. 자료 종류는 factor-returns입니다. 수익률은 실제 가격 변화와 일치해야 합니다.
  • 변동성 표면: underlying_price와 options. 각 유럽형 옵션의 계약 ID, 종류, 행사가, 만기, 매수·매도 호가, 금리, 배당수익률, 거래량·미결제약정을 서식대로 제공하세요. 자료 종류는 option-quotes입니다.
  • 내부자 클러스터: 한 발행사의 price, volume, filings. 공시 접수번호·발행사·소유자·거래 코드·수량·가격·원문 해시와 거래/접수/공개 시각을 각각 제공하세요. 자료 종류는 public-filings입니다.

dataset.metadata에는 자료 ID·출처 ID·제공자·거래소·시간대·세션·조정 기준·통화·원문 위치(dataset_id, source_id, provider, exchange, timezone, session, adjustment, currency, source_uri)가 필요합니다. symbols, units, retrieved_at, sampling_interval_seconds, periods_per_year, expected_rows, max_age_seconds도 실제 수집 조건에 맞춰 주세요. timestamp_semantics는 event_and_availability입니다. evidence_kind는 합성이면 SYNTHETIC, 실제 관측 자료면 OBSERVED로 선언합니다. 선언 자체가 원천 검증은 아닙니다.

가격 단위는 선언한 통화, 수익률은 소수(decimal), 주식 거래량은 주(shares), 옵션 거래량은 계약(contracts)입니다. 서로 다른 제공자나 사후 수정 자료를 자동으로 합치지 않습니다. 필요한 구성요소가 모두 알려진 가장 늦은 시각을 available_at에 기록하세요.

각 dataset.rows 행은 고유 id, 증가하는 event_at, 사건 이후의 available_at, 메타데이터와 같은 source_id, 연구군별 values, record_sha256을 가집니다. 최대 10,000행·2 MiB입니다. config의 학습/검사 창, 공백 구간, 수수료·슬리피지·차입비용, 자본·참여 한도는 서식에서 확인하고 연구 조건에 맞춰 입력하세요.

행을 수정했다면 원본 JSON을 request.json으로 저장하고 아래 표준 Python 코드로 새 prepared-request.json을 만드세요. 이 파일을 위 입력에 사용하면 됩니다. 해시는 편집한 행의 무결성을 묶을 뿐, 출처나 전략 성과를 인증하지 않습니다.

import hashlib, json
from pathlib import Path
request = json.loads(Path('request.json').read_text(encoding='utf-8-sig'))
for row in request['dataset']['rows']:
    content = {k: v for k, v in row.items() if k != 'record_sha256'}
    raw = json.dumps(content, sort_keys=True, separators=(',', ':'),
                     ensure_ascii=False, allow_nan=False).encode('utf-8')
    row['record_sha256'] = hashlib.sha256(raw).hexdigest()
with open('prepared-request.json', 'x', encoding='utf-8') as output:
    json.dump(request, output, ensure_ascii=False, indent=2, allow_nan=False)

입력 형식이 맞아도 자료 부족·누락·진부화 또는 검증 요건 부족이 남을 수 있습니다. 계산 결과의 진단과 차단 사유를 확인하세요. 합성 자료의 결과는 실세계 성과로 해석하지 않습니다.
