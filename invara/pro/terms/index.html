INVARA Pro 구독 운영 중

결제·세금·영수증은 Paddle이 처리하며 아래 정책이 구매에 적용됩니다.

이용약관

MIGARYOS의 INVARA Pro는 Windows에서 Codex 작업의 범위를 확인하고 실행 기록을 남기는 로컬 소프트웨어입니다. 이 서비스 조건은 현재 판매 중인 구매에 적용됩니다.

사용권 범위

유효한 유료 구독과 서명 사용권을 보유한 고객에게, 제공된 Pro 버전을 등록한 Windows 설치 한 곳에서 사용할 수 있는 제한적·비독점적·양도 불가 사용권을 제공합니다. 같은 고객이 소유하거나 관리하는 여러 프로젝트에 사용할 수 있습니다.

Pro의 재배포·재판매·재허가·공개 또는 소스 코드 배포는 허용하지 않습니다. 별도 INVARA Free core의 Apache-2.0 라이선스는 이 Pro 조건으로 변경되거나 제한되지 않습니다.

월 구독과 별도 비용

구독료는 월 USD 14.99이며 취소 전까지 매월 갱신됩니다. 적용되는 세금을 포함한 최종 결제 총액은 결제 전에 표시합니다. Codex 계정·구독 또는 API 비용은 Pro 요금에 포함되지 않습니다.

일반 구독 취소

일반 취소를 요청하면 현재 결제기간 끝까지 이용하고 다음 갱신을 중단합니다. 다음 청구를 피하려면 최소 24시간 전에 Paddle 영수증 링크, Paddle 지원 또는 hello@migaryos.com으로 취소를 요청해 주세요. 취소 요청 자체가 이미 청구된 금액의 환불을 뜻하지는 않습니다. 관련 경로는 Paddle 결제·취소·환불 안내에서도 확인할 수 있습니다.

환불 요청과 구독 종료

환불 요청은 구독 종료 의사로 접수합니다. 한국에서는 구매 후 7일 이내 미사용 구매는 전액 환불하며, 그 외에는 요청일부터 이미 결제한 기간 끝까지를 일할 계산합니다. EU·영국·튀르키예에서는 구매 후 14일 이내 취소 시 일할 환불합니다. 그 외 지역의 실수 결제는 청구 후 14일 이내 요청하면 일반적으로 환불 대상이며 심사를 거칩니다. 상세 기준과 적용 법령·Paddle 처리 조건은 환불 정책을 확인해 주세요.

환불에 따른 계약상 구독 종료와 실제 상태 반영은 구분됩니다. 환불이 승인되면 계약상 구독 종료 기준일은 최초 환불 요청일입니다. 구매자 확인 후 Paddle의 구독 종료·환불 절차를 진행하고 실제 상태를 확인합니다. 이메일 접수만으로 사용권 시스템이 자동 변경되는 것은 아니며, 이미 발급된 오프라인 사용권의 즉시 회수도 보장하지 않습니다.

사용권 확인과 구독 종료

Pro의 유료 작업 경계에서는 해당 설치의 서명 사용권을 확인합니다. 서명 사용권의 유효기간은 최대 24시간이며, 현재 사용권이 만료될 때까지 동기화 실패 중에도 사용할 수 있습니다. 취소·갱신 실패·만료는 이후의 유료 작업에 영향을 주며, 환불·철회도 이미 발급된 오프라인 사용권을 즉시 회수하지는 못합니다.

사용권이 만료되면 이후 유료 실행이 제한됩니다. 기존 로컬 증거와 기록 열람, 내보내기 및 Free 재검증 경로는 남습니다. 설치 이전이나 잃어버린 사용권의 자동 재발급을 약속하지 않습니다.
