INVARA는 에이전트 우선 설치와 Free 검증을 제공합니다. 결제·세금·영수증은 Paddle이 처리하고, 카드 정보는 Paddle 결제 화면 밖으로 전달되지 않습니다.

Windows용 로컬 작업 도구

“INVARA 설치해줘.”
Free로 시작하고, 필요하면 Pro를 적용하세요.

에이전트에게 설치를 요청하면 공식 패키지를 설치하고 현재 프로젝트를 초기화한 뒤 Free 검증을 실행합니다. 수동 명령 복사, 별도 활성화 파일 전달, 매달 입력은 정상 경로에 필요하지 않습니다.

한 고객의 Windows 설치 한 곳 · 취소할 때까지 자동 갱신
세금이 부과될 수 있으며, 최종 금액은 Paddle 결제 전에 표시됩니다. Codex/API 이용 비용은 별도입니다.

Paddle은 구매자에 대한 재판매자이자 Merchant of Record로 결제·세금·영수증을 처리하고, MIGARYOS는 INVARA Pro 제품·사용·지원을 공급합니다.

Pro 구독 시작

“Pro 결제하고 적용해줘”라는 요청 뒤 에이전트는 위 조건을 보여주고 반복 결제에 대한 한 번의 명시적 승인을 요청합니다. 승인 후 아래 공식 Paddle Checkout에서 결제하세요. 결제가 확인되면 설치 적용은 자동으로 이어집니다.

결제 창은 버튼을 눌렀을 때 열립니다.

에이전트 경로

  1. “INVARA 설치해줘.” — 공식 패키지 설치, 현재 프로젝트 초기화, Free 검증.
  2. “Pro 뭐가 좋아?” — 실제 Free/Pro 차이, USD 14.99/month, 세금 가능성, 자동 갱신, 별도 Codex/API 비용을 읽어 설명.
  3. “Pro 결제하고 적용해줘.” — 한 번의 명시적 승인 뒤 Paddle 화면을 열고, 결제 확인 후 자동 적용.

알아둘 점

  • 카드·결제 정보는 Paddle의 보안 화면에서만 입력합니다. 에이전트는 카드 정보를 요청하거나 보관하지 않습니다.
  • 취소하면 다음 갱신은 중단되고 이미 결제한 기간 동안 Pro가 유지됩니다. 취소·결제 관리는 공식 Paddle 화면에서 진행합니다.
  • Pro가 끝나도 Free 검증과 기존 로컬 기록은 유지됩니다.
  • 코드가 반드시 고쳐지거나 안전해진다는 보장, 작업 성공·정확성·시간 절감 보장은 없습니다.
