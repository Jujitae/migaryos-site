개인정보 처리 안내

MIGARYOS의 INVARA Pro는 로컬 작업, 결제, 사용권 확인 정보를 다음과 같이 구분하여 처리합니다. 현재 판매는 시작하지 않았으며, 결제·구독 관련 처리는 실제 판매 개시 이후 이용에 해당합니다.

정보와 처리 목적

영역정보와 목적
로컬 프로젝트·기록프로젝트 파일, 작업 요청, 검토·실행·결과 및 증거는 사용자가 정한 로컬 작업 경로에서 처리됩니다. 사용권 확인 요청에 프로젝트 파일이나 작업 증거를 포함하지 않습니다. 외부 Codex 실행 중 전달되는 내용은 사용자의 Codex 설정과 해당 서비스 이용 조건에 따릅니다.
Paddle 결제판매 개시 후 결제에 필요한 고객·거래 정보는 Paddle에서 처리합니다. Paddle의 정보 처리는 Paddle 개인정보 안내를 확인해 주세요. 이 페이지에는 결제 입력란이 없습니다.
사용권 확인활성화 자격과 설치 식별자가 사용권 확인 서비스로 전달됩니다. 서버는 구독·고객·거래 참조, 결제 기간·상태, 설치 연결, 활성화 자격의 지문, 서명 사용권, 상태 변경·확인 시각과 요청 집계 등 사용권 발급·갱신·중복 방지에 필요한 정보를 처리합니다. 카드 결제 정보를 이 사용권 요청에 넣지 않습니다.
로컬 활성화 정보설치 식별자와 서명 사용권은 로컬에서 사용합니다. 갱신용 자격은 Windows 현재 사용자 계정의 DPAPI를 사용해 저장합니다. 이는 무조건적인 보안 보장을 뜻하지 않습니다.
지원 문의사용자가 이메일로 보내는 연락 정보와 문의 내용은 문의 대응, 구매 확인 및 분쟁 대응에 사용합니다. 프로젝트 원본, 활성화 자격, 라이선스 키 또는 비밀번호를 문의에 넣지 마세요.
웹사이트 호스팅이 웹사이트는 GitHub Pages로 제공됩니다. GitHub는 서비스 제공 과정에서 IP 주소와 접속 기록을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 안내를 확인해 주세요.

보관과 삭제

구매·사용권 이행, 중복 발급 방지 및 분쟁 대응에 필요한 동안 관련 정보를 처리합니다. 필요가 종료되면 삭제하거나 익명화합니다. 다만 법령상 보존이 필요한 정보는 해당 의무가 끝날 때까지 분리하여 보존합니다. 이는 운영상 처리 원칙이며 자동 삭제나 정해진 날짜 안의 완료를 보장하지 않습니다.

사용자 컴퓨터에 있는 프로젝트와 증거의 관리는 사용자에게 남습니다. 서비스에 대한 삭제 요청이 사용자의 로컬 파일을 원격으로 지우는 기능은 아닙니다.
