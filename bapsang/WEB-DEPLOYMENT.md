# 밥상 웹 배포

공개 앱 주소: https://migaryos.com/bapsang/app/
버전: 1.3.0
원본 소스 커밋: `b9ca4ad7940619cf1224c13650846f665e5f9e2e`

`app/`은 밥상 원본의 `dist/`와 `npm run build:site`가 생성하는 `artifacts/web-runtime.js`, `artifacts/web-index.html`로 구성됩니다. 공개 index에는 회사 도메인의 canonical URL을 추가합니다. 단일 웹 번들은 업데이트 후 오래된 개별 모듈 캐시가 섞이는 것을 방지합니다. 이후 기능 변경 시 같은 방식으로 갱신합니다.

공개 상품 가격 새로고침은 밥상 소유자가 운영하는 https://bapsang-kitchen.mettl.chatgpt.site/api/retail/kurly/<reviewed-sku> 읽기 전용 서비스에 요청합니다. 개인 식단·알레르기·보유 재료·유통사 로그인은 전송하지 않으며, 검토한 공개 SKU만 조회합니다. 구매자 장바구니 자동 쓰기 연동은 없습니다.

회사 루트의 WIE 생성 페이지와 DNS·메일 설정은 수정하지 않습니다. 브라우저 저장소는 origin별입니다. 이전 ChatGPT Sites의 데이터는 해당 앱 정보의 백업 후 회사 주소의 백업 가져오기로 옮깁니다. 회사 주소 내의 기존 데이터와 설치형 앱의 기기 저장소는 기존 형식을 읽습니다.

1.2.0 장보기 UX 수정: 상품 가격을 자동으로 읽을 수 없어도 재료·살 양·기본 규격·예상 비용·선택 매장의 검색 링크를 표시합니다. 실제 조회 가격과 기본 예상 단가는 구분합니다. 가격 직접 등록은 선택 도구이며, 남은 재료 구매 화면과 구매 완료 저장을 제공합니다.

1.2.0: 컬리 외에 홈플러스 온라인 기본점포 37과 코스트코 공식 온라인 상품 가격을 자동 조회합니다. 홈플러스 쿠폰 조건은 상품별로 확인하며 최소 수량·주문 배수·조회 재고 상한을 반영합니다. 코스트코는 회원 구매가입니다. 공개 서버에서 세 매장의 실제 가격과 CORS를 확인했고, 같은 1.2.0 APK가 ARM 가상 Android 15에서 핵심 여정과 홈플러스 상품 표시 검사를 통과했습니다.

1.3.0: SSG 17개 공개 관측 상품과 롯데마트 제타 14개 상품을 추가해 총 192개 검토 옵션을 표시합니다. 롯데마트 공개 서버의 실제 갱신/CORS는 성공했습니다. SSG는 개발 환경의 상세 조회와 실제 가격/규격을 확인했지만 공개 서버에서는 요청 제한으로 갱신 실패했으므로 자동 갱신 완료로 간주하지 않습니다. 제한 후 대기를 공용 캐시에도 보존하며 원래 관측 시각을 바꾸지 않습니다. 새 APK는 동일 파일로 ARM 가상 Android 15 핵심 여정과 SSG/롯데마트 상품 표시를 통과했습니다.
