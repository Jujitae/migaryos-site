개인정보처리방침

1. 앱에 저장되는 정보

선택한 마트, 성인·아이의 인원 수, 끼니·요일, 조리도구, 식사 취향, 알레르기·기피 음식, 보유 재료, 예산, 생성된 식단, 구매·요리 완료 표시, 직접 등록·가져온 레시피, 원본 링크, 요리책, 추가 장보기 재료, 선택·직접 등록한 상품과 가격·구매 링크, 매장·배송지역 메모와 배송·멤버십 조건, 제품 성분 확인 및 사용자가 표시한 담기 진행 기록을 기기의 앱 저장 공간에 보관합니다. 알레르기 설정에는 건강과 관련된 내용이 포함될 수 있습니다. 개인의 이름, 생년월일, 전화번호, 광고 식별자나 로그인 계정은 입력받지 않습니다. 기기의 정밀 위치를 자동 수집하지 않으며, 사용자가 직접 입력한 매장·배송지역 메모는 기기에만 저장합니다.

2. 이용 목적과 외부 전송

입력한 정보는 기기에서 식단과 장보기 목록을 계산하고 사용자의 선택을 유지하기 위해서만 사용합니다. 설치형 앱은 화면, 재료, 레시피를 앱에 포함하며, 운영자 서버나 외부 AI에 식사 설정을 전송하지 않습니다. 광고·분석·추적 SDK를 사용하지 않습니다. 앱을 사용하기 위한 회원가입은 없습니다. 사용자가 ‘링크에서 레시피 읽기’를 선택하면 입력한 공개 웹사이트에 접속해 해당 페이지를 읽습니다. 이때 사이트 제공자에게 IP 주소와 요청한 URL 등 접속 정보가 전달될 수 있으며, 그 사이트의 정책이 적용됩니다. 알레르기·식단 설정이나 붙여넣은 레시피 내용을 해당 사이트나 AI 제공자에게 전송하지 않습니다. 직접 등록과 내용 붙여넣기는 네트워크 없이 사용할 수 있습니다. 장보기 상품 목록은 앱에 포함된 공개 자료 또는 운영자의 공개 상품 목록 파일에서 읽습니다. 상품 가격·재고 새로고침 시에는 운영자 서비스에 공개 상품 번호를 요청하고, 서비스는 해당 매장의 공개 상품 페이지를 조회합니다. 이때 운영자 서비스와 호스팅 제공자에게 IP 주소·요청한 상품 번호 등의 접속 정보가 전달될 수 있습니다. 식단·알레르기·기피 음식·개인 장바구니·유통사 로그인 정보는 가격 조회 서버로 보내지 않습니다. 운영자 서비스의 공개 상품 응답은 최대 15분간 캐시되며 사용자별 계정이나 장바구니를 생성하지 않습니다. 상품·검색 링크를 누르면 해당 외부 쇼핑몰로 이동하고 그 서비스의 정책이 적용됩니다.

3. 사용자가 직접 공유하는 정보

복사·공유·파일 저장·백업을 누르면 사용자가 선택한 다른 앱이나 저장 위치로 해당 내용이 전달될 수 있습니다. 백업에는 알레르기 등 개인 설정이 포함됩니다. 공유 전에 내용을 확인하고 저장 위치를 선택해주세요. 공유된 정보에는 선택한 외부 서비스의 정책이 적용됩니다.

4. 저장 기간과 삭제

설정은 사용자가 앱 정보에서 ‘모든 데이터 삭제’를 실행하거나 앱의 데이터를 삭제할 때까지 저장됩니다. 직접 내보낸 파일은 저장한 위치에서 별도로 삭제해야 합니다. 공유용 임시 파일은 다음 파일 내보내기 또는 모든 데이터 삭제 시 정리됩니다. 기기의 운영체제·백업 설정에 따라 앱 데이터가 백업되거나 앱 재설치 시 복원될 수 있습니다. Android 배포 설정에서는 자동 앱 백업을 꺼두었습니다. 밥상 자체의 클라우드 계정 동기화는 제공하지 않습니다.

5. 접근 권한

위치·카메라·마이크·연락처·건강 플랫폼 권한을 요청하지 않습니다. 파일 가져오기는 시스템 파일 선택기를 사용하고, 파일 공유는 시스템 공유 화면을 사용합니다. 다른 앱의 파일을 임의로 읽지 않습니다.

6. 아동에 관한 정보

성인 사용자가 가족 식사량을 계산할 수 있도록 아이의 인원 수만 입력할 수 있습니다. 아이의 이름·생년월일이나 개별 프로필은 저장하지 않습니다. 아동을 대상으로 한 광고나 추적은 없습니다.

7. 이메일 문의

사용자가 별도로 이메일 문의를 보내면 발신 이메일 주소와 문의 내용 등 사용자가 제공한 정보를 응답과 문제 해결 목적으로 처리합니다. 앱에 저장된 알레르기나 식단 정보가 문의 메일에 자동 첨부되지는 않습니다. 문의가 끝난 뒤 불필요한 정보는 삭제하며, 법령에 따른 보관 의무가 있으면 해당 기간만 보관합니다. 문의에 민감한 정보나 백업 파일 전체를 보내지 않아도 됩니다.

8. 웹 서비스 이용 시

웹 버전은 선택한 설정과 식단을 이용 중인 브라우저의 로컬 저장 공간에 보관합니다. 앱 정보의 삭제 기능이나 브라우저 사이트 데이터 삭제 기능으로 지울 수 있습니다. 웹 페이지를 제공하는 호스팅 서비스에는 접속 시 IP 주소, 브라우저 정보와 요청 주소 등 기술적인 접속 정보가 전달될 수 있습니다. 웹 버전은 글꼴을 Google Fonts에서 불러오며 해당 제공자에 접속 정보가 전달될 수 있습니다. 설치형 앱은 외부 글꼴을 불러오지 않습니다. 운영자는 웹 버전에도 광고·분석·추적 SDK를 넣지 않았습니다. 외부 음식 사진은 웹 호스팅에 포함된 로컬 파일로 제공합니다.

9. 변경과 문의

데이터 처리 방식이 바뀌면 앱과 개인정보처리방침에 변경 내용을 표시합니다. 문의처는 hello@migaryos.com입니다.
