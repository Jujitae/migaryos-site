밥상 도움말

밥상은 취향과 냉장고 재료에 맞춰 일주일 식단과 장보기 목록을 준비하는 집밥 도구입니다.

사용 방법

마트부터 선택하고 인원, 끼니, 요일, 주방 도구, 식사 취향, 알레르기·기피 음식, 보유 재료, 예산을 알려주세요. 결과에서 메뉴를 바꾸거나 장보기 목록과 레시피를 열 수 있습니다. 앱을 다시 열면 첫 화면의 ‘저장한 식단’으로 이전 식단을 볼 수 있습니다.

다음 주 식단과 직접 메뉴 고르기

식단 화면에서 다음 주로 이동한 뒤 ‘이 주 식단 만들기’를 누르면 기존 설정을 다시 입력하지 않고 새 식단을 만듭니다. 주간 표의 빈칸이나 메뉴를 누르면 해당 끼니를 직접 선택할 수 있습니다. 직접 선택에도 알레르기·기피 재료·조리도구 설정이 적용됩니다. 다른 주의 식단은 별도로 보관됩니다.

레시피와 요리책

레시피 화면에서 직접 요리를 등록하거나 게시물의 내용을 붙여넣어 가져올 수 있습니다. 원본의 재료·수량·단위를 확인한 뒤 저장합니다. 구조화된 Recipe 데이터가 있는 공개 웹페이지는 링크 읽기를 지원하며, 접근을 허용하지 않는 사이트와 SNS 영상은 내용 붙여넣기를 사용해주세요. 사진을 AI로 인식하거나 로그인한 SNS 영상을 자동 분석하는 기능은 현재 제공하지 않습니다. 직접 등록한 레시피의 영양 정보는 사용자가 입력한 값이며, 미입력 값은 표시하지 않습니다.

냉장고와 추가 장보기

냉장고에서 보유 수량을 수정하고 저장하면 장보기 목록에서 차감됩니다. 장보기 화면의 재료 추가로 식단 외에 필요한 재료도 합산할 수 있습니다. 가격은 선택한 마트의 실제 판매 가격이 아닌 공통 예시 단가입니다.

데이터 백업과 복원

앱 정보에서 데이터를 JSON 파일로 백업하고 시스템 파일 선택기로 가져올 수 있습니다. 복원은 기존 설정과 식단을 대체하므로 미리 백업하세요. 백업 파일에는 알레르기 등 개인 설정이 포함됩니다.

가격·영양·알레르기 안내

마트별 실시간 가격이나 할인은 연결되어 있지 않습니다. 가격과 영양은 참고용 추정치이며 실제 상품과 다를 수 있습니다. 알레르기는 앱에 등록된 대표 재료 기준으로 제외하므로, 실제 제품의 원재료와 교차접촉 가능성을 반드시 별도로 확인해주세요. 밥상은 의료 진단·치료 또는 개인별 영양 처방을 제공하지 않습니다.

브랜드와 콘텐츠

매장명은 장보기 목적지를 고르기 위한 표시입니다. 밥상은 표시된 유통사와 제휴하거나 유통사가 제공한 공식 앱이 아닙니다. 설치형 앱은 자체 제작 아이콘·삽화와 기기 기본 이모지를 사용하며, 제3자 음식 사진을 포함하지 않습니다.
